# امنیت در Git

## چرا نباید اطلاعات محرمانه را منتشر کنیم؟

اطلاعاتی مثل رمز عبور، API Key و کلید خصوصی نباید در GitHub قرار بگیرند، چون ممکن است دیگران از آن‌ها سوءاستفاده کنند.

## تفاوت فایل‌ها

- .env اطلاعات واقعی و محرمانه پروژه را نگه می‌دارد.
- config.example.env` فقط یک نمونه از تنظیمات است و اطلاعات واقعی ندارد.

## چرا حذف Secret کافی نیست؟

Git تغییرات قبلی فایل‌ها را در تاریخچه نگه می‌دارد. بنابراین اگر یک رمز را Commit کنیم، حذف آن از فایل فعلی باعث پاک شدنش از کامیت‌های قبلی نمی‌شود.

برای همین باید از ابتدا مراقب باشیم چه اطلاعاتی را در Git ثبت می‌کنیم.

## کارهایی که باید انجام بدهم

- فایل .env را در .gitignore قرار بدهم.
- اطلاعات واقعی را در GitHub منتشر نکنم.
- اگر کلیدی منتشر شد، آن را باطل و جایگزین کنم.
