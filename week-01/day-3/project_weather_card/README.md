 پروژه کارت آب‌وهوا

 معرفی پروژه
این پروژه یک کارت ساده آب‌وهوا با استفاده از زبان پایتون و کتابخانه  rich  است.

 توضیح فایل‌های پروژه

python-version : نسخه پایتونی را مشخص می‌کند که پروژه از آن استفاده می‌کند
uv.lock : نسخه دقیق کتابخانه‌ها و وابستگی‌های نصب‌شده را ثبت می‌کند
pyproject.toml :   اطلاعات، تنظیمات و وابستگی‌های پروژه را نگهداری می‌کند
.venv : محیط مجازی اختصاصی پروژه است و کتابخانه‌های موردنیاز در آن نصب می‌شوند
