## باگ ۳: نمایش اطلاعات مفسر پایتون

**مشکل:** عبارت f-string نوشته شده بود، اما با دستور print نمایش داده نمی‌شد.

**اصلاح:** از print برای نمایش نسخه و مسیر مفسر استفاده کردیم.

**نتیجه:** اطلاعات مفسر هنگام اجرای برنامه نمایش داده می‌شود.

## باگ ۴: اجرای ناخواسته هنگام وارد کردن ماژول

**مشکل:** تابع main به‌صورت مستقیم اجرا می‌شد؛ بنابراین هنگام وارد کردن فایل برای تست نیز برنامه اجرا می‌شد.

**اصلاح:** از شرط زیر استفاده کردیم:

```python
if __name__ == "__main__":
    main()
```

**نتیجه:** تابع main فقط هنگام اجرای مستقیم فایل اجرا می‌شود.

## درس آموخته‌شده: تفاوت REPL و Script

در محیط تعاملی پایتون (REPL)، نتیجه عبارت‌ها به‌صورت خودکار نمایش داده می‌شود.

اما هنگام اجرای یک فایل پایتون (Script)، عبارت‌ها به‌تنهایی نمایش داده نمی‌شوند و برای دیدن نتیجه باید از دستور print استفاده کنیم.
